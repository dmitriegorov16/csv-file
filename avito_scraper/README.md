# Avito CSV scraper

Сбор объявлений с Avito в CSV со столбцами:
`id, url, title, content, description, image, price, category, city, address`.

## Коротко: что нужно знать перед запуском

Пайплайн состоит из двух шагов, и они принципиально разные по сложности:

| Шаг | Чем берётся | Состояние |
|---|---|---|
| Ссылки на объявления | карты сайта Avito, обычный HTTP | **работает, бесплатно, секунды** |
| Данные карточек | HTTP-запрос страницы объявления | **нужен резидентский IP** |

Первый шаг решён полностью. Второй упирается ровно в одно — с какого IP
идёт запрос (см. следующий раздел). Всё остальное — парсер полей,
возобновляемость, ротация прокси, решение капчи — готово и оттестировано.

## Главное про блокировки: нужен резидентский IP

Avito блокирует **диапазоны датацентров целиком**, а не отдельные
«засветившиеся» адреса. Это проверено экспериментально:

| Что пробовали | Природа IP | Результат |
|---|---|---|
| IP обычного VPS | датацентр | HTTP 439, страница «Доступ ограничен» |
| Платный прокси steelproxy | датацентр | 429/439 |
| ~3000 публичных прокси | датацентр | дошли до Avito 39, заблокированы все 39 |
| 10 приватных Webshare, ранее не использованных | датацентр | 439 на **первом же** запросе |

Последняя строка решающая: адрес, выданный лично вам и никем до этого не
использованный, блокируется ещё до того, как с него сделан хоть один
запрос. Значит дело не в «сожжённости» конкретных адресов, и перебор
датацентровых прокси бесполезен при любом их количестве и цене.

Что из этого следует:

- **Решение капчи не помогает.** Оно работает (GeeTest через rucaptcha
  проходит), но против блокировки по IP бесполезно: Avito принимает
  решённую капчу, перезагружает страницу и блокирует снова.
- **Нужен резидентский или мобильный прокси** — адрес обычного домашнего
  провайдера. Например [DataImpulse](https://dataimpulse.com/): $1/ГБ,
  стартовый пакет $5 за 5 ГБ, не сгорает. С отключённой загрузкой
  картинок и CSS этого объёма хватает на весь тираж в 30000 карточек.
- Гео прокси не критично: Avito доступен и с зарубежных адресов.

Как только резидентский прокси есть:

```bash
export AVITO_PROXY_SERVER="http://логин:пароль@адрес:порт"
python fast_scrape.py --limit 20        # сначала проверить на двадцати
python fast_scrape.py                   # потом всю очередь
```

## Установка

```bash
cd avito_scraper
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Для варианта с браузером (`scraper.py scrape`) дополнительно:

```bash
playwright install --with-deps chromium
```

## Шаг 1. Ссылки на объявления — из карт сайта

```bash
python scraper.py sitemap --category avtomobili --max-urls 30000
```

Avito публикует карты сайта для поисковиков, и они отдаются обычным HTTP
**без фаервола, капчи и прокси** — даже с того IP, которому фронтенд
показывает «Доступ ограничен». В картах `item_<категория>_<id>_<N>.xml.gz`
лежат прямые ссылки на карточки, до ~50000 в одном файле, а самих карт
тысячи. 30000 ссылок собираются за секунды.

- `--category` — подстрока имени карты: `avtomobili`, `mebel_i_interer`,
  `odezhda_obuv_aksessuary`, `vakansii`, `akvarium` и т.д. Без неё берутся
  все категории подряд.
- `--max-urls` — сколько набрать за запуск. Дубликаты не добавляются,
  можно запускать повторно и докидывать в ту же очередь.

Список доступных категорий:

```bash
curl -s https://www.avito.ru/sitemap/index.xml | grep -o 'item_[a-z_]*' | sort -u
```

## Шаг 2. Карточки в CSV

```bash
python fast_scrape.py --limit 100
python fast_scrape.py                   # вся очередь
```

Качает страницы объявлений прямыми HTTP-запросами и разбирает поля из
серверной разметки (og-теги, JSON-LD, `data-marker`-блоки) — браузер не
нужен, страницы Avito отрендерены на сервере ради поисковиков.

Прогресс возобновляемый: обработанные ссылки пишутся в `data/done.txt`,
сквозной счётчик `id` — в `data/counter.json`. Повторный запуск продолжает
с того же места, поэтому собирать можно порциями хоть по 10 штук.

Полезные ключи:

- `--workers N` — сколько запросов параллельно
- `--cooldown N` — минимальная пауза между запросами с одного адреса;
  бережёт приватные прокси от бана
- `--only-mine` — только свои прокси, без публичных списков

## Прокси

Один адрес — через переменные окружения:

```bash
export AVITO_PROXY_SERVER="http://host:port"     # или socks5://host:port
export AVITO_PROXY_USERNAME="логин"
export AVITO_PROXY_PASSWORD="пароль"
```

Список своих адресов — файл `data/my_proxies.txt`, по одному в строке, в
формате выгрузки Webshare (`ip:port:логин:пароль`) или полным URL. Каталог
`data/` не попадает в git, поэтому пароли не утекут в репозиторий.

Пока жив хоть один свой адрес, публичные списки не используются: если
подмешать десяток приватных к трём тысячам публичных, на них придётся
десятая доля процента запросов, и толку от них не будет.

Проверить свои адреса, не сжигая их — по одному запросу на адрес с
паузами:

```bash
python check_my_proxies.py
```

Публичные списки (SOCKS5/SOCKS4/HTTP, ~6600 адресов из девяти источников)
качаются автоматически и кэшируются на 15 минут. Отдельно проверить, кто
виноват в отказах — мёртвые адреса или блокировка Avito:

```bash
python proxy_probe.py --count 200
```

## Вариант с браузером

`scraper.py scrape` делает то же самое через Playwright и умеет проходить
капчу Avito (GeeTest v4 / hCaptcha) через [rucaptcha](https://rucaptcha.com):

```bash
export RUCAPTCHA_API_KEY="ключ"
python scraper.py scrape --limit 10
```

Ключ храните только в переменной окружения, не в файлах репозитория.

Этот путь медленнее и дороже прямых запросов, а против блокировки по IP
всё равно не помогает — держится как запасной вариант на случай, если
Avito начнёт отдавать карточки только браузерам.

## Состав

| Файл | Назначение |
|---|---|
| `scraper.py` | карты сайта, сбор ссылок, вариант с браузером |
| `fast_scrape.py` | сбор карточек прямыми запросами, разбор HTML, CSV |
| `proxy_pool.py` | источники прокси, загрузка списков, кэш |
| `check_my_proxies.py` | осторожная проверка своих прокси |
| `proxy_probe.py` | диагностика: мёртвые прокси или блокировка Avito |
| `captcha_solver.py` | решение капчи Avito через rucaptcha |
| `test_parse.py` | тесты разбора HTML, без сети |

## Результат

`data/avito.csv` — колонки `id, url, title, content, description, image,
price, category, city, address`. `description` берётся из meta-описания,
а при его отсутствии — первые 100 символов `content` с многоточием.
`city` приводится к виду с заглавной буквы («Москва», «Волгоград»).
