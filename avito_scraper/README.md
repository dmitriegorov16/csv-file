# Avito CSV scraper

Скрипт на Playwright, который собирает объявления с Avito в CSV со
столбцами: `id, url, title, content, description, image, price, category,
city, address`.

## Важно про Avito и антибот

Avito активно защищается от автоматического сбора (антибот, капчи,
ограничение частоты запросов). Этот скрипт — простой вариант: реальный
Chromium через Playwright + случайные задержки между запросами. Он **не**
гарантирует, что Avito не заблокирует/не покажет капчу — особенно на
больших объёмах (~30000 объявлений). Рекомендации:

- Начинайте с маленьких тестовых прогонов (`--limit 20-50`), смотрите,
  не словили ли капчу.
- Если скрипт пишет `заблокировано (антибот/капча)` — остановитесь,
  подождите, при необходимости запустите с `--no-headless`, чтобы решить
  капчу руками в открывшемся окне браузера.
- Не увеличивайте частоту запросов (уменьшать `--delay-min/--delay-max`
  не стоит).
- Для 30000 объявлений реалистично потребуется несколько отдельных
  прогонов (скрипт возобновляемый — прогресс сохраняется в `data/state.json`
  и `data/urls.jsonl`, повторные запуски продолжают с того же места, а не
  начинают заново).

## Настройка в Codespaces

```bash
cd avito_scraper
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install --with-deps chromium
```

## Использование

Скрипт работает в два шага.

### 1. Собрать ссылки на объявления

```bash
python scraper.py collect --start-url "https://www.avito.ru/moskva/transport" --pages 5
```

- `--start-url` — ссылка на поиск/категорию/город на Avito (любая,
  главное чтобы на странице был список карточек объявлений).
- `--pages` — сколько страниц листинга обойти за этот запуск (Avito
  подставляет `&p=N`).
- Ссылки складываются в `data/urls.jsonl`, дубликаты не добавляются —
  можно запускать `collect` повторно с другими `--start-url`/`--pages`,
  очередь будет пополняться.

### 2. Обработать очередь и заполнить CSV

```bash
python scraper.py scrape --limit 50
```

- `--limit` — сколько объявлений обработать в этом запуске (удобно для
  тестовых прогонов). Без `--limit` — обработает всю оставшуюся очередь.
- Результат пишется построчно в `data/avito.csv`, `id` — сквозной
  счётчик 1..N, продолжается между запусками.
- Уже обработанные ссылки (успешно или нет — например, объявление снято)
  повторно не скачиваются.

Чтобы посмотреть на процесс глазами (например, при подозрении на капчу),
добавьте `--no-headless` к любой из команд.

## Как выбрать `--start-url`

Подойдёт любая ссылка на список объявлений на avito.ru — категория,
город, результат поиска по слову, с фильтрами и т.д., например:

```
https://www.avito.ru/moskva/transport
https://www.avito.ru/rossiya/nedvizhimost
https://www.avito.ru/volgograd?q=велосипед
```

## Что делать, если поля не извлекаются

Разметка Avito периодически меняется. Скрипт извлекает данные с
несколькими запасными вариантами (`data-marker` атрибуты, микроразметка
schema.org, `og:*` meta-теги, JSON-LD), но если конкретный `data-marker`
переименуют — соответствующее поле в `parse_item()` (`avito_scraper/scraper.py`)
нужно будет поправить под актуальную вёрстку.
